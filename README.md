## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html.
4. Right-click and select Open with Live Server, or open it directly in Chrome.

## Personalise Your Website

Before publishing, update these details:

- Your real email address.
- Your GitHub profile URL.
- Your LinkedIn profile URL.
- Your CV contact information.
- Any project descriptions that need updating.
- Your project screenshots and demonstration links.

Search for the following placeholders:

YOUR_EMAIL@example.com
YOUR_GITHUB_USERNAME
YOUR_LINKEDIN_USERNAME

Replace them with your actual information.

## GitHub Pages Deployment

1. Log in to GitHub.
2. Create a new public repository.
3. Upload all files and folders in this project.
4. Ensure index.html is in the repository root.
5. Open Settings.
6. Select Pages.
7. Under Build and deployment, select Deploy from a branch.
8. Choose the main branch.
9. Select the / (root) folder.
10. Click Save.

GitHub will publish your website.

Your website address will look like:

https://YOUR_GITHUB_USERNAME.github.io/
